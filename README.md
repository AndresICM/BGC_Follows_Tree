# BGC_Follows_Tree
This repository contains the main scripts used in the article BGCs Follow the Tree: Lineage-Associated Patterns of Biosynthetic Gene Cluster Distribution in Actinomycetota

Permanova_python.py: Python code used to run the PERMANOVA statistical test

20260617_HGT_GCF-Jaccard.R: R code to make Figure 3 with Mash distances vs Jaccard Distances

20260618_HGT_PCoA-Vegan.R: R code to make Figure 2.

20260618_Tree_HGT.R: R code to make Figure 1.
